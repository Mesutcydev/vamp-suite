# Support

Vamp Terminal is community-supported.

- Read the [README](README.md) for installation and Gatekeeper steps.
- Read [docs/AGENT_INTEGRATION.md](docs/AGENT_INTEGRATION.md) for CLI and automation
  use.
- Search existing GitHub issues before opening a reproducible bug report.
- Use GitHub Discussions for usage questions when Discussions are enabled.

Include the app version, macOS version, host/client network topology, exact steps,
and sanitized logs. Do not publish device fingerprints, addresses, credentials,
terminal output, personal files, or screen contents.

Security vulnerabilities follow [SECURITY.md](SECURITY.md) and must not be reported
in a public issue.

There is no guaranteed response time for general support. Commercial support is not
currently offered.
