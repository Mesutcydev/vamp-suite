App Stream / Vamp Stream · October 15, 2026

Implemented

  • One shared design system with native clear glass, ink and garnet ribbon artwork, adaptive color tokens, ivory primary actions and circular controls.
  • A Mac-first home. QR and private-address pairing live in an Add a Mac sheet, with Assistant / Companion available as an alternative.
  • Matching Sync and Assistant app libraries with search, All apps / Running / Favorites filters and context actions for windows and favorites.
  • A floating glass streaming dock. Disconnect is in the options menu; Hide stays visible outside the scrollable controls.
  • Matching settings, help, connection, error, permission and locked-Mac states. View Only connections do not offer the remote password form.
  • New app icon, symbol, wordmarks, launch artwork, light and dark wallpapers and this reusable brand kit.

Visual checks

  • iPhone: welcome, Add a Mac sheet, manual-address expansion, appearance settings, light and dark modes, library filtering, search, streaming controls, hide/reveal and gesture help.
  • iPad: centered library layout with a bounded content width.
  • Largest Dynamic Type: the filter changes to a full-width native menu, app text wraps, and decorative eyebrow labels yield space to functional content.
  • Increase Contrast: verified the opaque adaptive panel fallback on iPad. Reduce Transparency and Reduce Motion fallbacks were reviewed in code; those OS settings were not exercised in this pass. The Settings background toggle and the resulting solid help canvas were verified at runtime.

Visual comparison confirms the first-connection flow changed across the page. Pixel differences are expected for this full redesign and are not evidence of network or streaming correctness.

Practical limits

The simulator camera-denial prompt, the styled fallback, invalid manual-address feedback, icon switching and View Only help were exercised in the post-redesign audit. Live pairing, camera QR capture on physical hardware, live video and remote input were not re-tested. No pairing request was approved, no host permissions were changed, and no host was installed or restarted. Library and player screenshots use isolated, labeled design fixtures, compiled only in Debug. The AppStore archive is signed with the publisher’s existing distribution identity. TestFlight upload status is recorded below; it does not imply App Store review approval. The iOS 18 material fallback was compiled but not exercised on an iOS 18 device.
