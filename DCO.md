# Developer Certificate of Origin

Vamp Terminal uses the Developer Certificate of Origin (DCO) 1.1. By adding a
`Signed-off-by` trailer to a commit, a contributor certifies that the contribution
meets the terms of the DCO.

Read the canonical DCO text at
[developercertificate.org](https://developercertificate.org/).

Sign a commit with:

```bash
git commit --signoff
```

The name and email in the trailer must identify the contributor. The project does
not require a contributor license agreement or copyright assignment.
