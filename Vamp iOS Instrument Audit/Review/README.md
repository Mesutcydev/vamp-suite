# Vamp Assistant iOS / iPadOS — refinement review

Use the **iPhone** and **iPad** folders here for the current named review images. Other folders in the parent audit directory retain earlier validation artifacts; they are not the final review set.

- Both light and dark appearances are included.
- Production-view fixtures cover chat, multiline draft, keyboard-focused composer, enlarged text, Sessions, New Session, Bots, Builder Chat/Run, Models, Tools, Approval, Pairing, Connection Lost, Sharing, and Settings.
- iPad also includes split navigation, portrait/landscape chat, and reduced-width layout.
- Images 25/26 exercise long warning and approval text at enlarged sizes.
- Fixture filenames deliberately say `fixture`: they use production UI with isolated sample state, not live Mac execution.
- Keyboard-focused fixture images exclude the separate system keyboard window. The separate system capture includes the actual simulator keyboard.
- Portrait/landscape resized-window images validate layout constraints, not physical-device rotation or all keyboard interactions.

Source/build details and remaining end-to-end checks are recorded in the accompanying audit report. Nothing in this folder is a claim that an IPA was installed or published.
