04Security

Private by network and identity.

Keep every host on a trusted LAN or private Tailscale network. Never forward its ports to the public internet.

Explicit approvalA pending connection is not trusted until you verify it on the Mac.
Authenticated videoVideo and input travel only after the selected host protocol authenticates the client.
Revocable devicesRemove a saved Stream device from the host that approved it.
No public relayVamp does not require a project-operated relay or public port forwarding.
