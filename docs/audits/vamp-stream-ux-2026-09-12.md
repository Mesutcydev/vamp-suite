# Vamp Stream UX audit — 12 September 2026

Scope: current working-tree implementation of onboarding, host selection, Assistant pairing and QR scanning, connection feedback, app selection, and the recently revised splash/background. This is a source-based audit with previously rendered small and standard portrait splash previews, not a completed device usability study. No app code changed during this audit. Preserve the requested splash animation and all pairing, trust, permission, and session guarantees.

The visual identity is clear. The highest-value work is making interrupted and failed actions understandable, followed by adaptive layouts. Stronger contrast alone does not ensure every state is readable: the pairing progress state still switches to disabled styling.

P1 means fix before the next release; P2 means next UX iteration. Device-dependent layout and performance risks are identified as such.

## Delivery process

1. Fix QR recovery, attempt cancellation, and loading-state contrast together. Verify with an invalid QR followed by a valid one, a delayed pairing response followed by Cancel, and successful/failed pairing. Never weaken trust validation to make these tests pass.
2. Validate layout and accessibility on a small phone, a standard phone, and iPad in portrait/landscape; include default and largest text, VoiceOver, Reduce Motion, Increase Contrast, and Reduce Transparency. Check the keyboard-open form and long host names. Inspect actual rendered controls, not just source colors.
3. Add recovery checks for unreachable Mac, busy Mac, denied camera permission, expired code, connection interruption, and disappearing app window. Each state should expose a clear next action and preserve valid user input.
4. Consolidate Stream-specific visual styles after the state behavior is correct. Review screenshots of initial, disabled, loading, error, and success states together, including text over the brightest artwork region.
5. Test functional changes with focused regression tests and the required repository checks. Establish a short release walkthrough from fresh install to first streamed app and from saved Mac to reconnect. For streaming interruption, verify reattachment without unintended session teardown.

Acceptance: invalid scans recover without leaving/reopening the whole pairing flow; Cancel prevents late local activation; loading feedback stays legible; onboarding and primary actions remain reachable at largest text sizes; failures have relevant recovery actions; forgetting a Mac clearly explains its consequence. Device and live-host validation remains outstanding for this audit.
